# LinkedIn Post Template

Construí un framework de automatización QA con enfoque Senior usando Playwright + TypeScript.

Qué implementé:
- Arquitectura CPOM (Page Objects + Component Objects reutilizables).
- Flujos híbridos E2E: API + UI + validación visual.
- Sesión autenticada reusable con setup y storageState.
- CI con quality gate, ejecución paralela por suites y artefactos de reportes.

Stack:
- TypeScript
- Playwright
- JSON Schema (AJV)
- GitHub Actions
- Allure
- Husky + ESLint + Prettier

Resultados:
- Suite estable para demo local.
- Pipeline preparado para validación continua.
- Proyecto estructurado para escalar cobertura sin perder mantenibilidad.
